# FitLife
FitLife - это программа фитнес-трекер для заботы о здоровье пользователя.
При запуске FitLife:
- Знакомится с пользователем — спрашивает его имя и возраст.
- Собирает данные — узнаёт его вес и рост.
- Считает результаты — рассчитывает Индекс Массы Тела, или ИМТ.
- Даёт рекомендации — подсказывает дневную норму воды
